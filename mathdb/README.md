# MathDB open problems

Campaign results against open problems sampled from [MathDB](https://mathdb.com/database).
One folder per problem, named by its MathDB number: `<id>/` holds the final `solution.md`
(or `proof.md`), the dependency `proof-skeleton.md`, the `literature-audit.md` that checks
the problem was genuinely open, the executable verifier and its recorded output, and
`Problem<id>.lean` where a formalization exists. See [`LEAN.md`](LEAN.md) for what the Lean
files certify.

These folders deliberately do **not** follow the Lake-project layout used by the
problem folders at the repository root: each is a single Lean module plus a markdown proof,
not a self-contained Lake project.

This index counts mathematically complete campaign results. “Internally
verified” means the proof has passed the local dependency audit, executable
checks where relevant, and at least one independent hostile read. It does not
mean published, peer reviewed, or guaranteed novel beyond the documented
literature search.
